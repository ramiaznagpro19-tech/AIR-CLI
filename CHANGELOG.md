# Changelog

All notable changes to AIR CLI are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased] - 2026-10-27

### Changed

- Rebranded the project as AIR CLI and moved the default config directory from `~/.qwen` to `~/.air`.
- Kept the original Apache 2.0 license and added a NOTICE preserving the upstream attribution to Qwen Code (Alibaba) and Gemini CLI (Google).
- Removed the Qwen/Gemini branding from the public package metadata and README text.
- Dropped the Alibaba-specific channel integrations and retained the supported provider protocols: OpenAI, Anthropic, Gemini, and Vertex AI.
- Added configuration examples for OpenRouter, Ollama, Mistral, and DeepSeek.
