# Changelog

All notable changes to AIR CLI are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed

- Rebranded the project as AIR CLI and aligned the public package metadata to the AIR naming.
- Kept the original Apache 2.0 LICENSE and added a NOTICE preserving the upstream lineage from Qwen Code (Alibaba) and Gemini CLI (Google).
- Replaced the default global config directory with `~/.air`.
- Removed the public Qwen/Gemini branding from the main project documentation and package metadata.
- Kept the supported provider protocols: OpenAI, Anthropic, Gemini, and Vertex AI.
- Added configuration examples for OpenRouter, Ollama, Mistral, and DeepSeek.
